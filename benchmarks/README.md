# Оценка сжатия контекста

Эксперимент измеряет, какую долю поискового контекста можно удалить без ухудшения ответа AliceAI-T5.

## Сравниваемые методы

- полный контекст
- случайные фрагменты той же суммарной длины
- BM25
- векторный поиск
- модель повторного ранжирования
- модельно-зависимый экстрактор

## Бюджеты

Каждый метод проверяется при сохранении 5, 10, 20 и 50 процентов токенов исходного контекста. Полный контекст служит верхней точкой по объёму и основной точкой сравнения по качеству.

## Показатели

- правильность итогового ответа
- полнота подтверждающих фрагментов
- доля утверждений без опоры на источники
- число входных токенов
- время кодирования входа
- задержка первого выходного токена
- полное время ответа

Проверочная часть используется для выбора порогов. Итоговая часть открывается один раз после фиксации модели и настроек.
