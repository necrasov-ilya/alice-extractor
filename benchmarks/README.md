# Оценка извлечения

AliceAI, Qwen и система правил получают один и тот же текст счета и должны вернуть JSON по [схеме](../schemas/invoice-v1.schema.json). PDF и распознавание изображений в первую оценку не входят.

## Набор данных

Версия `v1` содержит 50 синтетических счетов:

| Раздел | Документы | Использование |
| --- | ---: | --- |
| `development` | 30 | шаблоны и примеры |
| `validation` | 10 | выбор настроек |
| `test` | 10 | финальная оценка |

```bash
.venv/bin/alice-validate-dataset
```

Команда проверяет схему, арифметику, манифест, дубликаты, идентичность организаций и SHA-256. Подробности: [data/v1/README.md](data/v1/README.md).

## Показатели

- корректность JSON и соответствие схеме
- точность и полнота каждого поля
- микро- и макро-F1
- доля значений, найденных в исходном тексте
- время кодирования и первого токена
- скорость следующих токенов
- пиковая объединённая память

Результаты теста публикуются для всего раздела, а также отдельно для рублевых и нерублевых счетов.

## Замер исполняемого пути

MacBook Pro с M1 Max и 64 ГБ памяти, macOS 26.6.2, Python 3.12, PyTorch 2.10 и Transformers 5.14.1. Запрос содержит 57 входных и 17 выходных токенов.

| Показатель | Исходный путь | Новый путь | Ускорение |
| --- | ---: | ---: | ---: |
| Холодный запрос | 14,950 с | 10,848 с | 1,38 раза |
| Прогретое кодирование | 8,042 с | 1,451 с | 5,54 раза |
| Первый проход декодера | 1,403 с | 0,293 с | 4,80 раза |
| Следующие токены | 19,11 токена/с | 19,59 токена/с | 1,03 раза |
| Прогретый запрос | 10,282 с | 2,561 с | 4,01 раза |

Полные числа: [results/m1-max-64gb-runtime.json](results/m1-max-64gb-runtime.json). Качество ответов этим замером не подтверждается.
