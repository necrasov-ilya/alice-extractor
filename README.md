# Alice Extractor

Эксперимент по модельно-зависимому сжатию поискового контекста для [AliceAI-T5-35B-A0.6B](https://huggingface.co/yandex/AliceAI-T5-35B-A0.6B). Экстрактор должен оставлять минимальный набор фрагментов, достаточный AliceAI для правильного ответа.

Обычный поиск выбирает текст по близости к запросу. Здесь полезность фрагмента определяется по его влиянию на ответ целевой модели.

```text
запрос и найденные документы
             │
             ├─ базовые методы: BM25, векторный поиск, повторное ранжирование
             │
             └─ обучаемый экстрактор → минимальный контекст
                                      │
                                      ↓
                                  AliceAI-T5
                                      │
                                      ↓
                             ответ с подтверждениями
```

## Исследовательский вопрос

Можно ли сократить русскоязычный поисковый контекст в 5–10 раз без ухудшения ответа AliceAI и получить измеримое сокращение задержки на Apple Silicon?

Эксперимент сравнивает полный контекст, BM25, векторный поиск, модель повторного ранжирования и экстрактор, обученный на влиянии фрагментов на ответ AliceAI. Основные показатели: правильность ответа, сохранность подтверждающих фрагментов, доля оставшихся токенов и время обработки.

## Состояние

Сейчас в репозитории готова техническая основа для эксперимента:

- локальная загрузка смешанных весов int8/BF16 на MPS
- вычисление только восьми выбранных экспертов из 512
- потоковая подготовка квантизированной контрольной точки
- раздельный замер кодирования входа и декодирования
- численные тесты маршрутизируемого экспертного слоя

Обучающий набор и модель отбора контекста ещё не опубликованы. План эксперимента находится в [PLAN.md](PLAN.md), формат данных описан в [docs/data-format.md](docs/data-format.md).

## Установка

Нужны Mac с Apple Silicon, Python 3.12 и достаточный объём объединённой памяти.

```bash
uv venv --python 3.12 .venv
uv pip install --python .venv/bin/python -e .
```

## Подготовка весов

Контрольная точка создаётся из зафиксированной ревизии исходной модели. Экспертные матрицы переводятся в int8, остальные параметры сохраняют исходный тип.

```bash
.venv/bin/alice-quantize-checkpoint \
  --revision a0d71f58c40d6affe461797b30b35ff47f52a5f2
```

Итоговые файлы появятся в `local/aliceai-t5/data/int8`. Подробности находятся в [docs/quantization.md](docs/quantization.md).

## Проверка локального запуска

```bash
.venv/bin/alice-extractor \
  --model-dir local/aliceai-t5/model \
  --weights-dir local/aliceai-t5/data/int8 \
  "Какой вывод следует из приведённых документов?"
```

```bash
.venv/bin/alice-runtime-benchmark \
  --model-dir local/aliceai-t5/model \
  --weights-dir local/aliceai-t5/data/int8
```

## Локальные файлы

Весовые файлы, кэши и пользовательские документы хранятся в `local`, который полностью исключён из Git.

```text
local/
  aliceai-t5/
    model/
    data/int8/
  huggingface/
```
