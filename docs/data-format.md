# Формат поисковой задачи

Одна строка JSONL описывает запрос, набор найденных документов, эталонный ответ и подтверждающие его фрагменты.

```json
{
  "id": "search-000001",
  "query": "Почему организация изменила условия поставки?",
  "documents": [
    {
      "id": "doc-1",
      "title": "Условия поставки",
      "text": "Полный текст документа",
      "source_url": "https://example.org/document",
      "license": "license-id"
    }
  ],
  "reference_answer": "Условия изменились из-за новой даты отгрузки.",
  "evidence": [
    {
      "document_id": "doc-1",
      "start": 120,
      "end": 178
    }
  ],
  "category": "cause",
  "language": "ru"
}
```

`start` и `end` задают границы в символах строки `text`. Эталонный ответ должен полностью подтверждаться указанными фрагментами. Документы из итоговой части не должны встречаться в обучении и проверке.

Полученная разметка экстрактора хранится отдельно от исходной задачи и включает идентификатор фрагмента, вероятность его полезности, способ построения цели и точную ревизию AliceAI.
