# Локальные модели и веса

Все крупные или полученные извне модельные файлы хранятся внутри `local`. Каталог исключён из Git целиком. Дополнительные маски по расширениям в `.gitignore` защищают от случайного добавления весов из другого каталога.

## Структура

```text
local/
  aliceai-t5/
    model/
    scripts/
    data/int8/
  huggingface/
```

`local/aliceai-t5` содержит рабочую локальную копию исходного эксперимента. Она нужна для воспроизведения замеров и переноса исправлений в публикуемый код. Окружение `.venv` намеренно не копируется.

`local/huggingface` является корневым каталогом для собственных клонов Hugging Face. Производный репозиторий модели находится в `local/huggingface/AliceAI-T5-35B-A0.6B-MPS-ExpertInt8`. Официальную AliceAI-T5 при необходимости следует клонировать в отдельный каталог `local/huggingface/AliceAI-T5-35B-A0.6B`, сохраняя исходную историю и лицензионные файлы.

Публикуемый код должен получать пути через настройки или переменные окружения. Абсолютные пути пользователя запрещены. Скрипт первоначальной настройки в будущем должен уметь проверить наличие `config.json`, токенизатора, модельного кода и всех ожидаемых шардов без загрузки их в Git.

Подготовка весов выполняется командой `alice-quantize-checkpoint`. Она сохраняет точную ревизию базовой модели и параметры преобразования в `quantization_config.json`. Для текущих локальных весов конфигурация и индекс совпадают с ревизией `a0d71f58c40d6affe461797b30b35ff47f52a5f2` официального репозитория Yandex.

## Правила

- Не добавлять веса с принудительным флагом Git.
- Не хранить в репозитории пользовательские документы.
- Не считать локальную квантизацию отдельной моделью без карточки метода, проверки качества и соблюдения лицензии.
- Не изменять официальный клон Hugging Face во время разработки запуска. Производные файлы размещать отдельно.
- Перед выпуском проверять список отслеживаемых файлов на расширения весов и секреты.
